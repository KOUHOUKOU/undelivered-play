# Undelivered — playable build

Open the page and click *Start* (or *Film mode* to watch it play by itself). About 9 minutes. Best in a desktop browser (Chrome / Edge), 16:9 window, with headphones. Esc = pause menu (chapters, transcript, subtitle size, sound).

- Current version: v4 (the full film, Prologue · Maze · Puzzle · Riddle).
- The previous build (rc2) is still playable at [`rc2/`](rc2/).

Text: James Joyce, "A Painful Case", *Dubliners* (1914), public domain. Piano samples: Salamander Grand Piano by Alexander Holm, CC BY 3.0.
