# Undelivered — playable build

Open the page and click *Start* (or *Film mode* to watch it play by itself). About 9 minutes. Best in a desktop browser (Chrome / Edge), 16:9 window, with headphones. Esc = pause menu (chapters, transcript, subtitle size, Music and Effects volume).

- Current version: v4 final (2026-10-04): the full film with its original score (piano and strings).
- Earlier v4 builds: [`v4d/`](v4d/), [`v4c/`](v4c/), [`v4b/`](v4b/), [`v4a/`](v4a/).
- The previous build (rc2) is still playable at [`rc2/`](rc2/).

Text: James Joyce, "A Painful Case", *Dubliners* (1914), public domain. Music: original score. Piano samples: Salamander Grand Piano by Alexander Holm, CC BY 3.0. String samples: VSCO 2 Community Edition by Versilian Studios, CC0.
